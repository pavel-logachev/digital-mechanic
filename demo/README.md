# Демо-ролик

Ролик https://mechanic.logachev.net/demo.mp4 снят скриптом с живого стенда, одним непрерывным проходом, без монтажа.

- `tools/record_demo.py` – Playwright открывает стенд в Chrome на экране телефона 390×844 и проходит сценарий: инструкция и крупный шрифт, парк и 7 языков, С1 (отклонение → объяснение со ссылками → страница руководства), С2 (вопрос голосом: звук `q-c2.wav` подается в браузер как микрофон и распознается настоящим сервисом стенда, затем подробный ответ по шагам и заявка в ТОиР с номером), С3 (сбой записи), ошибка самой модели (узел, которого нет у двигателя), С4 (сводка главного механика и история машины). Кадры экрана идут через CDP screencast, время каждого шага и ожиданий модели пишется в `build/main-marks.json`.
- `tools/render_demo.py` – собирает ролик 1920×1080: телефон по центру, слева список сценариев и функций сверх ТЗ, справа подпись к текущему шагу и подсветка элемента на экране. Ожидания ответа модели ускорены ×3 и помечены в кадре, все остальное идет в реальном времени. `--clean` – тот же проход без подписей и подсветки.
- `tools/process_voice.py` – чистка и сведение дикторского голоса: шумоподавление по профилю пауз, вырезка посторонних звуков, перенос фраз точно под события на экране, компрессия и громкость −16 LUFS, вопрос механика из ролика чуть тише голоса. Видеоряд при этом не меняется.

```
cd demo/tools
python record_demo.py [https://mechanic.logachev.net]   # build/main-raw.mp4 + разметка, ~3 мин
python render_demo.py                                    # ../demo-video-captions-no-voice.mp4
python render_demo.py --clean                            # ../demo-video-no-voice.mp4
python process_voice.py voice.webm                       # ../demo-final.mp4 – ролик с озвучкой
```

Нужны Python 3.12, `playwright` с установленным Chrome, `pillow`, `numpy`, `noisereduce`, FFmpeg в PATH. Шрифты подписей – Segoe UI из `C:/Windows/Fonts` (на Linux поменяйте путь в `render_demo.py`). Перед записью стоит сбросить журнал заявок мок-ТОиР, иначе номер заявки в кадре будет не `TKT-0001`.
