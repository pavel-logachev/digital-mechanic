# Цифровой механик

ИИ-агент для механика автопарка: результат акустической диагностики двигателя, ответы по руководствам с указанием документа и страницы, черновик заявки на ремонт с подтверждением механика.

Решение задачи «Цифровой механик» хакатона Softline «ИИкузница» (2026).

Разработка ведётся во время спринта 26–28 ноября 2026 года. Описание, запуск и состав компонентов появятся здесь по ходу работы.
