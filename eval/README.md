# Оценка качества

Код оценки лежит здесь, а данные – вне Git. По требованию организаторов (чат задачи, 26.11) PDF руководств, RAG-индексы и любые тексты, извлечённые из руководств, в открытый репозиторий не попадают. Контрольные вопросы с проверочными цитатами, ответы агента и трассы оценки хранятся в каталоге `EVAL_DATA_DIR` (по умолчанию `data/eval/`, исключён из Git) и передаются жюри по запросу.

В репозитории – только агрегаты: `quality-final-2026-11-26.json` (итог на 72 вопросах для трех моделей), `quality-final-2026-11-27.json` (перепроверка основной модели после правок 27.11), `e2e-fleet-summary.json` (полный цикл на 50 машинах), `cost-probe.json` (токены, время и глубина переранжирования), `quality-summary.json` (промежуточный срез спринта). Методика и выводы – `QUALITY.md`.

Запуск (нужны `data/manuals/*.pdf`, собранный индекс и данные оценки в `EVAL_DATA_DIR`):

```
python -m eval.retrieval_eval      # поиск по страницам
python -m eval.agent_eval          # агент на контрольных вопросах
python -m eval.quality_eval        # агент + LLM-судья (--provider/--model – сменить модель агента)
python -m eval.e2e_fleet --base http://127.0.0.1:8000   # полный цикл на 50 машинах
python -m eval.quality_summary     # пересчёт итогов без API
```
