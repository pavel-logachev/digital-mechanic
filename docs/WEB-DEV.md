# Локальная проверка веб-интерфейса

Из корня `digital-mechanic`:

```text
C:/Users/pavel/Documents/Projects/iikuznitsa/sprint-env/.venv/Scripts/python.exe web/dev_fake_api.py
```

Откройте `http://127.0.0.1:8174/`. Черновики и заявки остаются в памяти тестового сервера. Микрофон записывает аудио, но тестовый `/api/transcribe` возвращает готовую фразу на указанном языке, а не распознает звук. Числовой ответ тестового чата есть только для примера с ЯМЗ-236М2.

```text
uv run --no-project --with playwright python web/check_ui.py
uv run --no-project --with playwright python web/check_ui.py screens
```

Первая команда проверяет поиск, сортировку и фильтры парка, все семь языков, крупный текст на 360 px, голосовой ввод, переходы браузера, ошибки сети и форму заявки. Вторая обновляет все снимки на тестовом стенде и проверяет, что подтвержденная заявка появилась в карточке машины. `MECHANIC_BROWSER` позволяет указать другой Chromium, `MECHANIC_SCRATCH` – каталог для временного WAV.

## Проверка распознавания на рабочем API

Стенд `http://127.0.0.1:8000/` должен отдавать текущий `web/` и принимать `POST /api/transcribe`. Сценарий отправляет один запрос диагностики и один запрос распознавания; оба расходуют средства. Заявку он не создает, распознанный вопрос не отправляет.

```text
uv run --no-project --with playwright python web/check_ui.py real_voice --real-wav C:/path/to/russian-question.wav
```

Для WAV произнесите «Как проверить зазор клапанов?». Playwright подаст WAV в Chromium вместо микрофона, а браузер сам запишет его через MediaRecorder.
