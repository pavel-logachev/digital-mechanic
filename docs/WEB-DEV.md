# Локальная проверка веб-интерфейса

Из корня `digital-mechanic`:

```text
C:/Users/pavel/Documents/Projects/iikuznitsa/sprint-env/.venv/Scripts/python.exe web/dev_fake_api.py
```

Откройте `http://127.0.0.1:8174/`. Необязательный аргумент после имени файла меняет порт. Сервер работает только локально; черновики и новые заявки хранятся в памяти процесса и не отправляются в настоящий ТОиР.

| Что показать | Как открыть |
| --- | --- |
| Отклонение, история и прошлая заявка | Гаражный `103` → `B418HK98` → последняя проверка (17.11.2026). |
| Чат с точной цитатой и PDF | В той же проверке спросить «Какой тепловой зазор?». Нажать `[1]`, перелистнуть физическую страницу PDF, увеличить масштаб. |
| Черновик и квитанция | Нажать «Создать заявку», отредактировать поля и подтвердить отправку. Если меняете приоритет, укажите причину: она добавится к заключению. |
| Норма | `M333YK47` → последняя проверка (19.11.2026). |
| Сбой записи | `P456AT178` → последняя проверка (19.11.2026); на графике вместо оценки — `×`. |
| Главный механик | Одноименная кнопка над списком машин → любая строка приоритетного списка. |

В `screens/` десять снимков Chromium шириной 390 px. Основные переходы проверены против тестового API; интеграция с рабочим бэкендом, моделью и ТОиР — отдельная проверка. Числовой ответ в тестовом чате предусмотрен только для показанного примера с ЯМЗ-236М2; другие вопросы не получают придуманных нормативов.
